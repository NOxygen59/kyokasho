**Version :** Kyōkasho **0.5** (V4) — cartes de révision (FSRS) et export Anki.

## Installation

Ouvrir `Kyokasho-0.5.0.tipa` avec **TrollStore** (remplace la version précédente, tout est gardé).

## Modifications de ce build (21 octobre 2026)

- **Créer une carte** : bouton ＋ dans le popup du dictionnaire (toucher ou survol), dans la
  recherche de la bibliothèque et sur chaque mot de l'onglet Mots. ✓ si le mot a déjà une carte.
  - Champs remplis tout seuls : mot, lecture, furigana, sens, accent, fréquence, phrase de la page
    (mot en gras), source « Titre · p. N », **image de la ligne** du manuel, **audio**.
- **Révisions** (barre latérale de la bibliothèque, avec le nombre de cartes dues) : plein écran,
  carte au centre, 4 réponses à droite avec le prochain intervalle. Calcul **FSRS**.
  - Clavier (Magic Keyboard) : Espace = montrer / Bien, 1–4 = réponses, ⌘Z = annuler, Échap = fermer.
  - Bilan de fin de séance ; « Reviens à HH:mm » quand une carte en apprentissage revient bientôt.
- **Navigateur de cartes** : recherche, filtre par paquet, édition des champs, suspendre, supprimer, stats.
- **Réglages → Révisions et export Anki** : nouvelles cartes / jour, révisions max, rétention,
  début de journée, paquets, éditeur du modèle (recto / verso / CSS + aperçu), image / audio,
  AnkiMobile, **export .apkg et CSV**, nettoyage des médias.
- **Accueil** : vignettes des PDF entières et centrées (elles étaient coupées).
- **Page 1** par document : menu ••• du lecteur → « Cette page est la page 1 » (ou appui long dans
  la bibliothèque). Tous les numéros suivent le manuel imprimé (chiffres romains avant).
- **Dictionnaire au survol du curseur** (trackpad) : bouton sous 辞, popup placé sans cacher le texte.
