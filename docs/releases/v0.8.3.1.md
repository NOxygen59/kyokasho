**Version :** Kyōkasho **0.8.3.1** — fusion de PDF.

## Installation

Ouvrir `Kyokasho-0.8.3.1.tipa` avec **TrollStore** (remplace la version précédente, tout est gardé).
Si GitHub est connecté dans Réglages → À propos, le bandeau de la bibliothèque propose « Installer ».

## Modifications de ce build (22 octobre 2026)

- **Fusionner des PDF** (bibliothèque → Outils) : choisir plusieurs PDF dans Fichiers, les ranger en les faisant
  glisser, en ajouter ou en retirer, nommer le résultat, fusionner. Ensuite : « Enregistrer dans Fichiers » et / ou
  « Importer dans Kyōkasho ». Tout se fait sur l'iPad (PDFKit) ; les PDF protégés par mot de passe sont ignorés.

## Vérifié / non vérifié

- ✅ Fusion vérifiée sur le Mac (même code PDFKit) ; l'app compile pour l'iPad.
- ❌ Pas testé sur l'iPad (sélecteur, glisser pour ranger, enregistrement dans Fichiers).
