**Version :** Kyōkasho **0.1** (V1) — lecteur, annotations, page vers IA, Google Drive.

## Installation

Télécharger `Kyokasho-0.1.0.tipa` et l'ouvrir avec **TrollStore** sur l'iPad.
Google Drive direct : suivre d'abord la section « Google Drive : configuration » du README
(identifiant OAuth à créer), puis recompiler. Sans ça, l'import Drive passe par l'app Fichiers.

## Contenu de ce build (20 octobre 2026)

- Bibliothèque, import Fichiers/Drive (copie locale, SHA-256, sans doublon), reprise de lecture.
- Lecteur PDFKit : simple/double page, paginé/continu, gauche→droite / droite→gauche, première
  page seule, rognage auto, découpe des doubles pages, rotation par page, fond, transition,
  zones de tap (+ inversion), double tap zoom, barres masquées, aperçu de page.
- Surlignage, dessin PencilKit, signets, sommaire, recherche ; commentaires + export Markdown.
- Page vers IA (image + prompts), panneau claude.ai à côté.
- Google Drive direct (lecture seule, mises à jour des cours en gardant les annotations).
- Réglages globaux et par document, thème sombre par défaut.

- ✅ 24 tests unitaires (import, base, rognage, découpe, zones de tap, géométrie, Markdown…).
