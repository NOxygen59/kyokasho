**Version :** Kyōkasho **0.3** — nouvelle interface « Atelier », pensée paysage.

## Installation

Ouvrir `Kyokasho-0.3.0.tipa` avec **TrollStore** (remplace la version précédente, tout est gardé).

## Modifications de ce build (20 octobre 2026)

- **Interface « Atelier »** (outil de studio) : fond graphite quadrillé, panneaux flottants,
  une couleur par fonction — turquoise lecture, ambre annotation, vermillon japonais, violet IA,
  bleu import.
- **Bibliothèque** en paysage : barre latérale (Tous / En cours / Drive, import, banc d'essai,
  réglages, progression totale) + planche de couvertures.
- **Lecteur** : capsule titre (page + moteur OCR), capsule d'actions, **barre d'outils** à gauche,
  **pellicule des pages** en bas, **panneau d'étude** à droite (ouvert d'office en paysage) :
  - *Texte* : texte de la page (OCR), changer/comparer les moteurs, **traduction DeepL**,
    **lire tout le document** (les scans deviennent cherchables) ;
  - *Mots* : kanji de la page (le dictionnaire au toucher arrive en V3) ;
  - *Notes* : notes de la page, export Markdown ;
  - *Repères* : signets, surlignages, recherche.
- **Recherche** : trouve aussi le texte des pages photo déjà lues (📷).
- **DeepL** (option) : clé dans Réglages → Traduction, envoi seulement sur « Traduire ».
- **Google Drive** plus simple : assistant en 5 étapes dans l'app, identifiant collé dans l'app,
  plus besoin de recompiler.
