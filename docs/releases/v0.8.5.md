**Version :** Kyōkasho **0.8.5** — « Analyser le document entier » : plusieurs IA relisent chaque page, vote et note de fiabilité.

## Installation

Ouvrir `Kyokasho-0.8.5.tipa` avec **TrollStore** (remplace la version précédente, tout est gardé).

## Modifications de ce build (22 octobre 2026)

- **Analyser le document entier** (bibliothèque → appui long sur un livre) : chaque page est lue par l'OCR habituel,
  puis par OvisOCR2, GLM-OCR et **Qwen3-VL-4B** (nouveau, gros modèle de 4 milliards de paramètres, 3,1 Go, Apache-2.0),
  ceux qui sont installés, un à la fois. Une ligne est confirmée quand deux lectures indépendantes concordent :
  **note de fiabilité** du livre, pages les moins sûres, désaccords avec toutes les lectures et un **choix conseillé**
  (majorité, ou dictionnaire à égalité). « Appliquer les choix conseillés », choix ligne par ligne ou « garder tel
  quel ». Écran allumé pendant l'analyse ; arrêt possible, reprise là où elle s'était arrêtée.
- **Mémoire étendue** (droits TrollStore) pour les gros modèles.
- Réglages → Modèles : Qwen3-VL-4B dans le groupe « Relire et vérifier avec l'IA ».

## Vérifié / non vérifié

- ✅ Sur Mac, dans les conditions d'iOS 16 (Metal 3.0 forcé) : Qwen3-VL-4B et OvisOCR2 lisent sans faute des pages
  japonaises (dont du vocabulaire de design d'intérieur) ; vote et fiabilité couverts par des tests ; code relu.
- ❌ Pas testé sur l'iPad : durée réelle (≈ 1 min par page et par modèle attendu), mémoire, chaleur. En cas de souci :
  Réglages → Outils → Diagnostic → partager le journal.
