## Modifications de ce build (22 octobre 2026)

- **Plantage au lancement corrigé** (`Symbol not found: std::exception_ptr::__from_native_exception_pointer`) : le
  rétroportage de MLX coupait les contrôles de version de la bibliothèque C++ ; le binaire appelait alors une fonction
  absente du système d'iOS 16. Contrôles rétablis, et la seule partie qui les exigeait (`std::format` des messages
  d'erreur de lecture/écriture de MLX) est remplacée par du code qui produit exactement les mêmes messages
  (fork `NOxygen59/mlx-swift`, `Source/Cmlx/ios16-overrides`).
- Tout le reste est identique à la 0.8.4.
