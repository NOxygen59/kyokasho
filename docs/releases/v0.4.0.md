**Version :** Kyōkasho **0.4** (V3) — dictionnaire japonais au toucher, façon Yomitan.

## Installation

Ouvrir `Kyokasho-0.4.0.tipa` avec **TrollStore** (remplace la version précédente, tout est gardé).

Ensuite : **Réglages → Dictionnaires → Importer** un ou plusieurs dictionnaires Yomitan (.zip),
par exemple Jitendex ou JMdict (mots), KANJIDIC (kanji), JPDB / Innocent Corpus (fréquences),
Kanjium (accents). Aucun dictionnaire n'est fourni avec l'app.

## Modifications de ce build (20 octobre 2026)

- **Bouton 辞** dans la barre d'outils du lecteur : touche un mot sur la page → popup avec
  lecture (furigana), sens, étiquettes, **forme conjuguée reconnue** (食べさせられた → 食べる,
  causatif · passif · passé), fréquence, **accent** (schéma), kanji.
  - Marche sur le texte du PDF **et** sur les pages photo déjà lues par l'OCR.
  - Le mot reconnu est surligné sur la page.
  - Touche un mot dans une définition → nouvelle recherche (pile avec retour arrière).
  - Touche un kanji → fiche kanji (lectures on/kun, sens, statistiques).
  - ▶︎ audio : dossier local (Fichiers › Kyōkasho › Audio) puis JapanesePod101 (en ligne,
    seulement quand tu touches ▶︎ ; option lecture auto).
- **Onglet Mots** du panneau d'étude : tous les mots de la page (avec lecture, sens court,
  nombre d'apparitions) + grille des kanji ; touche → popup.
- **Dictionnaire** dans la bibliothèque : recherche manuelle (kana, kanji, formes conjuguées),
  historique.
- **Réglages → Dictionnaires** : import en tâche de fond (gros fichiers OK, mémoire faible),
  activer / désactiver, ordre, suppression ; profils (longueur de scan, nombre de résultats,
  affichage), sources audio.
- Moteur de déconjugaison et conversions de texte **portés de Yomitan** (GPL-3.0, voir
  THIRD_PARTY_NOTICES.md).
