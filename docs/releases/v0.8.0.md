**Version :** Kyōkasho **0.8.0** — scans fiables, double page, texte mis en forme.

## Installation

Ouvrir `Kyokasho-0.8.0.tipa` avec **TrollStore** (remplace la version précédente, tout est gardé).
Les pages déjà lues par l'OCR sont relues une fois (positions des caractères plus précises).

## Modifications de ce build (21 octobre 2026)

- **PDF « photo » réparés** : leur couche de texte vide (ou faite de blancs) les faisait passer pour des PDF
  numériques. Dictionnaire au survol / toucher et furigana passent maintenant bien par l'OCR.
- **Dictionnaire plus juste sur les scans** : avec NDLOCR, PP-OCRv5 (s'il est installé) mesure la place de
  chaque caractère ; alignement caractère par caractère quand les deux lectures diffèrent un peu.
- **Furigana sur les scans** : les pages affichées sont lues automatiquement quand les furigana sont actifs.
- **Double page** : deux pilules dans le panneau d'étude (une par page affichée) ; texte, mots, notes et OCR
  suivent la page choisie.
- **Texte mis en forme** (panneau Texte) : titres, paragraphes, colonnes, tableaux ; « Brut » pour le texte ligne
  par ligne ; la copie donne du Markdown.
- **Panneau d'étude ouvert d'office** en paysage à l'ouverture d'un manuel.
