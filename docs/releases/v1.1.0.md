**Version :** Kyōkasho **1.1.0** — pages préparées une seule fois, choix Auto / Simple / Double.

## Installation

Ouvrir `Kyokasho-1.1.0.tipa` avec **TrollStore** (remplace la version précédente, tout est gardé).

## Modifications de ce build (22 octobre 2026)

- **« Préparation des pages » une seule fois** : les pages remises à la même taille sont gardées (cache disque) ;
  aux ouvertures suivantes, le livre s'ouvre directement. Refait une fois seulement si le PDF change (pages
  ajoutées). « Effacer le cache » les supprime aussi (refaites à la prochaine ouverture).
- **Pages : Auto / Simple / Double** (Réglages → Apparence et lecture → Pages) : Auto (par défaut) = une page en
  portrait, double en paysage ; Simple ou Double choisis = toujours respectés.
