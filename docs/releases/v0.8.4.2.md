**Version :** Kyōkasho **0.8.4.2** — l'IA locale marche sur iOS 16 (plus de plantage à la vérification de la double page) ; mode diagnostic.

## Installation

Ouvrir `Kyokasho-0.8.4.2.tipa` avec **TrollStore** (remplace la version précédente, tout est gardé).

## Modifications de ce build (22 octobre 2026)

- **Plantage au début de « Vérifier la double page » corrigé.** MLX compilait certains calculs graphiques sur
  l'iPad en Metal 3.1 (iOS 17) ; iOS 16 refusait, et l'erreur arrêtait l'app. Désormais (fork `NOxygen59/mlx-swift`) :
  Metal 3.0 sur iOS 16, le `bfloat` logiciel est aussi dans les sources compilées sur l'iPad, et une erreur de MLX
  pendant le chargement d'un modèle devient un message au lieu d'un arrêt.
- **Mode diagnostic** (Réglages → Outils → Diagnostic) : journal des chargements de modèles, durées, mémoire et
  erreurs ; visible dans l'app ou dans Fichiers → Kyōkasho → Diagnostics, à partager pour aider à corriger un bug.
  Les erreurs de MLX y sont notées même si l'app s'arrête.

## Vérifié / non vérifié

- ✅ Sur le Mac, **dans les conditions d'iOS 16** (Metal 3.0 forcé) : OvisOCR2 lit correctement une page japonaise
  (24 s chargement compris) avec le MLX rétroporté. Binaire de l'iPad contrôlé (plus de bfloat natif, plus de
  symbole absent d'iOS 16).
- ❌ Pas encore vérifié sur l'iPad ; GLM-OCR pas testé sur le Mac (même moteur, autre modèle).
