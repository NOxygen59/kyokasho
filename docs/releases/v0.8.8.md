**Version :** Kyōkasho **0.8.8** — Qwen réparé sur iOS 16, document lu par l'IA, furigana et doutes d'après l'IA, nouveaux thèmes.

## Installation

Ouvrir `Kyokasho-0.8.8.tipa` avec **TrollStore** (remplace la version précédente, tout est gardé).

## Modifications de ce build (22 octobre 2026)

- **Traduction Qwen3-VL réparée sur iOS 16** : le calcul « d'attention » ne se compilait pas sur la carte graphique
  d'iOS 16 (« Unable to build metal library ») ; trou comblé dans le fork MLX par un code équivalent.
- **Document lu par l'IA** à l'import et à l'ouverture (OvisOCR2, pages pas encore lues seulement, ≈ 30 s par
  page) : pastille « IA : … » avec barre en % et « Voir le détail » (journal en direct) ; plusieurs PDF lus l'un
  après l'autre ; continue hors du document.
- **Furigana d'après le texte de l'IA** : lectures justes (texte d'OvisOCR2) posées sur les caractères de la page.
- **Caractères douteux revérifiés** à chaque lecture de la page, et marqués là où l'OCR diffère de l'IA.
- **Double page** : la page choisie dans le panneau reste, même zoomé sur l'autre page.
- **Thèmes à fonds dessinés** : Washi, Architecte (plan bleu), Intérieur (plan d'appartement), Lumière du soir,
  Encre et or, Sakura ; aperçu réel dans le choix ; couleurs du thème dans le dictionnaire et les cartes.
