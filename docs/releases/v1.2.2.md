# Kyōkasho 1.2.2 — chat dans le lecteur

## Installation

Ouvrir `Kyokasho-1.2.2.tipa` avec **TrollStore** sur l'iPad habituel (iOS 16.6.1).
Installer par-dessus la version précédente conserve les livres, notes, cartes et conversations.

## Modifications (24 octobre 2026)

- **Chat dans la fenêtre OCR** : nouvel onglet à côté de Texte, Dico, Notes et Repères. Les conversations d'un livre sont disponibles aussi depuis l'accueil ; plusieurs discussions peuvent être créées sans effacer les précédentes.
- **Questions liées au manuel** : chaque nouvelle question recherche ses propres passages OvisOCR2. Une relance peut utiliser le dernier échange. Dans le lecteur, un bouton insère la page ouverte dans la question et les pages consultées sous une réponse sont ouvrables.
- **Choix du modèle** : Qwen3-VL-4B existant ou Qwen3.5-4B optionnel. Qwen3.5 se télécharge dans l'app (environ 3,06 Go) ; aucun poids n'est inclus dans le paquet. Un seul modèle IA est chargé à la fois.
- **Suivi** : la pastille d'activité et la page Stockage reconnaissent Qwen3.5. L'ancien historique du chat reste disponible.

## Vérifié / non vérifié

- Compilation iOS générique et archive Release réussies ; paquet TrollStore, version 1.2.2 et build 37 contrôlés sur Mac.
- Aucun simulateur ni iPad utilisé. Le chargement, la vitesse et la qualité de Qwen3.5 sur l'iPad, ainsi que les interactions du nouveau chat, restent à confirmer par l'utilisateur.
