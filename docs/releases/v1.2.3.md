# Kyōkasho 1.2.3 — chat et relecture OCR

## Installation

Ouvrir `Kyokasho-1.2.3.tipa` avec **TrollStore** sur l’iPad habituel (iOS 16.6.1).
L’installation par-dessus la version précédente conserve les livres, notes, cartes et conversations.

## Modifications (24 octobre 2026)

- **Chat du livre** : les réponses partent de la question actuelle et des passages retrouvés dans le manuel, sans imposer le thème du design d’intérieur. Une nouvelle question ne reprend l’échange précédent que si elle y fait explicitement référence.
- **Furigana** : bouton direct à côté de « … » pour les afficher ou les masquer sur la page. Dans le panneau Texte, les pages OCR majoritairement verticales sont présentées de droite à gauche avec les furigana dans le sens vertical.
- **OCR** : les corrections proposées par OvisOCR2 sont accessibles depuis l’onglet Texte. « Rescanner » relit réellement la page choisie avec OvisOCR2, même si une lecture est enregistrée, puis propose les différences à accepter. L’ancien score de fiabilité de cette page est retiré après une nouvelle lecture.

## Vérifié / non vérifié

- Compilation iOS générique et archive Release réussies sur Mac. Le paquet TrollStore contient Kyōkasho 1.2.3 (build 38).
- Aucun simulateur ni iPad utilisé. Le rendu vertical et le comportement des nouveaux boutons restent à confirmer sur l’iPad.
