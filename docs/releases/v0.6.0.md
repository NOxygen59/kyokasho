**Version :** Kyōkasho **0.6** (V5) — 3 nouveaux moteurs OCR, thèmes, lecteur plus fluide.

## Installation

Ouvrir `Kyokasho-0.6.0.tipa` avec **TrollStore** (remplace la version précédente, tout est gardé).

Les modèles OCR ne sont **pas** dans l'app : Réglages → Japonais → OCR → « Modèles à télécharger ».

## Modifications de ce build (21 octobre 2026)

- **OCR** : 3 moteurs à télécharger à la demande (reprise si coupé, fichiers vérifiés) :
  - **NDLOCR-Lite** (Bibliothèque nationale du Japon, ~157 Mo) : livres japonais, colonnes verticales ;
  - **PP-OCRv5** (PaddleOCR, ~21 Mo) : petit et rapide ;
  - **GLM-OCR** (IA, ~1,25 Go) : relit chaque ligne trouvée par PP-OCRv5, précis mais lent.
  - Auto : texte du PDF → NDLOCR → PP-OCRv5 → Apple Vision. Moteurs dans les menus et le banc d'essai.
- **Lecteur** :
  - « Dictionnaire » dans le menu de sélection de texte d'iOS ;
  - barre d'outils flottante déplaçable (verticale, horizontale, rétractée) ;
  - bande des pages rétractable, case pour aller à une page (numéro imprimé) ;
  - un tap ne tourne plus la page ; flèches et touches ← → avec un clavier ;
  - option Pencil → dictionnaire (Réglages → Lecture → Apple Pencil).
- **Thèmes** : Atelier + Forêt, Braise, Sable, Lagon (Réglages → Apparence). Réglages rangés par thème.
- **Suppression des documents réparée.**
- **Mémoire et fluidité** : un seul PDF ouvert partagé, miniatures légères, PDF libéré à la fermeture,
  préparation du document hors du fil principal, bibliothèque et recherche allégées.

## Vérifié / non vérifié

- ✅ Tests unitaires verts. NDLOCR-Lite, PP-OCRv5 et GLM-OCR testés **sur le Mac** avec les vrais modèles
  (texte japonais généré) : horizontal et vertical lus sans faute, sauf GLM-OCR vertical (1 kanji sur 6 confondu).
- ✅ L'app compile pour l'iPad.
- ❌ **Rien testé sur l'iPad** : vitesse et mémoire des moteurs (surtout GLM-OCR), thèmes, barre flottante,
  menu de sélection, Pencil, suppression, gain réel de fluidité sur un gros PDF.
