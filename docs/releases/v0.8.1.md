**Version :** Kyōkasho **0.8.1** — boutons de page réparés, furigana cliquables dans le texte extrait, nouvelle icône.

## Installation

Ouvrir `Kyokasho-0.8.1.tipa` avec **TrollStore** (remplace la version précédente, tout est gardé).

## Modifications de ce build (21 octobre 2026)

- **Boutons page précédente / suivante réparés** : en double page, ils restaient dans la même double page
  (PDFKit n'avance que d'une page). Ils s'affichent aussi quand les barres sont visibles, sans clavier.
- **Réglages par document** : « Pagination et réglages de ce document » ne touche que ce document, et n'enregistre
  que quand tu changes vraiment quelque chose.
- **Furigana dans le texte extrait** (panneau Texte, bouton ふりがな) : lectures du dictionnaire Yomitan installé
  (sinon analyseur d'iOS) ; un appui sur un mot ouvre la fenêtre compacte du dictionnaire (ajout de carte possible).
- **Menu de la page rangé** : Affichage / Cette page / réglages du document.
- **Réglages → Modèles** : page à part pour tous les modèles, avec sous chacun le lien du projet et du fichier.
- **Nouvelle icône** (教 doré, livre ouvert, sceau 書).

## Vérifié / non vérifié

- ✅ Tests unitaires verts ; l'app compile pour l'iPad.
- ❌ **Pas testé sur l'iPad.** Moteurs de mise en page (PP-DocLayout, DocLayout-YOLO de MinerU) : pas encore
  intégrés (téléchargement de test à valider). Gestes / zoom : en attente de précisions.
