# Kyōkasho 1.2.1 — discuter d'un manuel avec Qwen

## Installation

Ouvrir `Kyokasho-1.2.1.tipa` avec **TrollStore** sur l'iPad habituel (iOS 16.6.1).
Installer par-dessus la version précédente pour conserver les livres, notes, cartes et réglages.

## Modifications (23 octobre 2026)

- **Chat du livre** : appui long sur sa carte → « Discuter du livre avec Qwen », une fois toutes ses pages lues par OvisOCR2 et Qwen3-VL-4B installé.
- **Réponses fondées sur le manuel** : recherche locale de quelques passages parmi les textes Ovis déjà enregistrés ; pages consultées indiquées dans la réponse. Une analyse à plusieurs moteurs, si elle existe, apporte un indice de concordance OCR.
- **Coût limité** : aucun nouveau modèle ni nouveau scan ; le chat n'envoie que les passages utiles à Qwen et évite la reformulation quand la question retrouve directement le texte.

## Vérifié / non vérifié
