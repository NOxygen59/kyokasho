# Kyōkasho 1.2.4 — lecture et navigation corrigées

## Installation

Ouvrir `Kyokasho-1.2.4.tipa` avec **TrollStore** sur l’iPad habituel (iOS 16.6.1).
L’installation par-dessus la version précédente conserve les livres, notes, cartes et conversations.

## Modifications (24 octobre 2026)

- **Chat du livre** : une demande comme « p. 6 » utilise la lecture OvisOCR2 de cette page, sans substituer des passages d’autres pages. Si cette lecture manque, le chat l’indique.
- **Corrections OCR** : dans l’analyse du document, une action accepte les différences OvisOCR2 déjà enregistrées sur tout le livre. Les retouches manuelles et les lignes de formule restent intactes ; aucun nouveau scan n’est lancé.
- **Formules** : les commandes LaTeX reconnues par OvisOCR2 sont affichées sous forme de symboles lisibles dans la mise en page IA. Comparer les formules importantes à la page originale : la reconnaissance de leurs caractères peut encore se tromper.
- **Lecture** : furigana des légendes verticales mieux orientés ; le panneau OCR ancré occupe sa propre colonne lors du changement de page. Le glissement à deux doigts du trackpad n’est plus utilisé pour tourner la page, avec un réglage pour revenir à l’ancien comportement.

## Vérifié / non vérifié

- Compilation iOS générique et archive Release sur Mac. Paquet TrollStore 1.2.4 (build 39).
- Aucun simulateur ni iPad utilisé. Le zoom et le déplacement au trackpad, les furigana et la fenêtre OCR restent à confirmer sur l’iPad.
